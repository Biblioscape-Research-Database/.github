## Biblioscape Highlights

- **Records Plus Folders:** Biblioscape bibliographic records live in a Windows database, not only in a flat .bib, with folders that match a project you already run.
- **Notes On The Source:** Biblioscape notes folder stores comments on papers you collected, which a metrics tool never does.
- **Research Database, Not A Compiler File:** Biblioscape research database is for searching and organizing; you export when a Word or TeX document needs a list.
- **Classic Desktop Bibliography:** Biblioscape reference database is the older full-client idea: one library on a PC you administer.
- **Not JabRef’s TeX-Native .bib And Not Citavi’s Task Planner:** Nearby products; this seat is the notes-and-records database.

## What Is Biblioscape

Biblioscape is a Windows bibliographic and research-notes program. Scholars who already keep reprints and typed comments open Biblioscape research database so records are not scattered across Word files. Biblioscape bibliographic records are the citations. Biblioscape notes folder is the commentary. Biblioscape reference database is the whole library on disk.

JabRef would be the better first choice if the only output is a `.bib` for a compiler. Citavi would be the better first choice if the project is quotations, categories, and a Word add-in with tasks. Biblioscape sits in the desktop-database middle: folders, notes, and a library you search by field.

Store sources you collected, purchased, or were given permission to keep. Notes should be your words. Do not import an entire commercial catalog you are not licensed to copy.

## Starting with Biblioscape

Prerequisites: A PC you administer and a set of sources you are allowed to store.

1. **Prepare:** Gather reprints and notes for one project you already run, not the entire career at once.
2. **Configure:** Create Biblioscape research database and name folders after that project.
3. **Test:** Enter a few Biblioscape bibliographic records and a comment in Biblioscape notes folder.
4. **Refine:** Set fields and keywords you will actually search, then import only permitted records.
5. **Apply:** Grow Biblioscape reference database as reading continues.
6. **Maintain:** Backup the database with the PDFs you are allowed to keep, and prune dead projects.
